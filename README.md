# 栖屿 · 白庭 / QIYU · WHITE COURT

一个伪装成高端私宅营销站的滚动恐怖叙事网页。开头是克制的编辑式奢宅页面，越往下，文案、监控、户型图与表单越不对劲，最终进入一条没有出口的走廊。

**在线浏览：<https://1012142137.github.io/qiyu-white-court/>**  
GitHub 仓库：<https://github.com/1012142137/qiyu-white-court>

## 打开

直接双击 `index.html` 即可。图片、样式与脚本均为本地相对路径，不需要联网。

也可以在本目录启动一个本地服务器：

```powershell
python -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/>。

## 体验建议

- 右上角「声音 OFF」可开启环境音；声音由 Web Audio 实时合成，没有额外音频文件，默认关闭。
- 页面约 1.8 万像素高，从亮色营销页逐渐转入夜间住区、监控、户型图、预约页与终局。
- 后段包含闪烁画面、突然出现的影像与音效；已适配 `prefers-reduced-motion`。
- 建议独自浏览，佩戴耳机。

## 技术

纯静态 HTML / CSS / JavaScript，无构建步骤、无外部依赖。图片位于 `assets/`，全部本地化。

## 声明

「栖屿·白庭」为虚构品牌，页面仅作互动叙事与视觉实验，不收集任何信息。照片素材来自 Unsplash 与 Pexels。
